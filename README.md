Supply Chain Management (SCM) Web Application

A modern front-end based Supply Chain Management (SCM) prototype developed using HTML, CSS, and JavaScript. This project simulates real-world supply chain operations including inventory management, supplier coordination, customer order processing, shipment tracking, and dashboard analytics — all without requiring a backend server.

📌 Project Overview

Traditional supply chain systems often face challenges such as:

Poor inventory visibility
Delayed communication
Inefficient order tracking
Lack of transparency
Complex deployment and infrastructure requirements

This project demonstrates how modern front-end technologies can simulate a complete SCM workflow using lightweight browser-based architecture.

The application is designed as a prototype system that operates entirely in the browser using localStorage and JSON-based data simulation.

🏗️ System Architecture

The application follows a layered front-end architecture:

Layer	Technology	Purpose
Presentation Layer	HTML5, CSS3	User Interface
Business Logic Layer	JavaScript (ES6)	Data Processing
Storage Layer	localStorage, JSON	Data Persistence
Analytics Layer	Chart.js	Data Visualization
Deployment Layer	GitHub Pages / Netlify / Vercel	Hosting
